# 扩展指南：新指标、新策略、新图表

系统留了三个扩展口。**指标和策略不需要改系统代码**：在 `user/` 下放一个 Python 文件就会被自动发现。
图表分三种情况，只有“新的绘图方式”需要改界面代码。

你可以自己写，也可以用中文把想法告诉 Claude，由它写代码、写测试、跑回测并截图给你看（见最后一节）。

## 1. 新指标

**放在哪里**：`user/indicators/<名字>.py`，一个文件可以放一个或多个指标。

**模板**：`user/indicators/donchian.py`（唐奇安通道）。最小写法：

```python
from collections import deque
from pydantic import Field
from trader.core.models import Bar
from trader.indicators.base import Indicator, IndicatorParams, OutputSpec, WarmupSpec, register_indicator


class MyParams(IndicatorParams):
    period: int = Field(default=20, ge=1, le=500, description="回看根数")   # 界面表单自动生成


@register_indicator
class MyIndicator(Indicator):
    name = "my_ind"                       # 唯一的注册名
    description = "一句话说明"
    Params = MyParams
    outputs = [OutputSpec("value", "line", "price")]   # 输出：名字、画法、画在主图还是副图
    scope = "continuous"                   # 跨天延续；每天重新开始的（如日内 VWAP）写 "session"

    def __init__(self, params: MyParams) -> None:
        super().__init__(params)
        self.closes: deque[float] = deque(maxlen=params.period)

    def warmup(self) -> WarmupSpec:        # 需要多少历史数据才出有效值（系统自动往前取数）
        return WarmupSpec(bars=self.params.period)

    def update(self, bar: Bar) -> dict[str, float | None]:   # 每根收盘 bar 调用一次
        self.closes.append(bar.close)
        if len(self.closes) < self.closes.maxlen:
            return {"value": None}         # 数据不够时返回 None
        return {"value": sum(self.closes) / len(self.closes)}
```

**要点**
- `update` 是唯一的计算入口，图表、回测、回放、实盘都调用它，所以各处数值一定一致。
- 画法五选一：`line` 线、`histogram` 柱、`band` 通道线（虚线）、`marker` 标记点、`hline` 阶梯水平线；
  位置：`price` 叠在主图，`separate` 单独的副图。超出这五种需要扩展界面（见第 3 节）。
- 会话指标（`scope = "session"`）实现 `on_session_open(self, day)`，每天开始时重置；`day.open` 是常规开盘时刻。
- 不能读写文件、联网或读系统时间（测试会扫描检查）。

**怎么看效果**
1. 保存文件 → 研究版菜单“代码 → 重新加载自定义指标和策略”（不用重启）。
2. 图表的“指标…”对话框里会出现它，填参数后添加。
3. 或者在 notebook 里：`compute_indicator("NVDA", "5m", "my_ind", "2026-10-01", "2026-10-01", period=20)`。
4. 命令行：`uv run trader indicators list` 能看到它；加载出错会显示错误信息。

## 2. 新策略

**放在哪里**：`user/strategies/<名字>.py`。

**模板**：`user/strategies/ema_cross.py`（均线交叉）、`user/strategies/orb_breakout.py`（开盘区间突破，带括号单和 `ctx.state`）。

**结构**

```python
from pydantic import Field
from trader.core.models import Bar, Reason
from trader.strategy.base import Strategy, StrategyParams, register_strategy


class MyParams(StrategyParams):
    symbol: str = "SPY"
    timeframe: str = "5m"
    notional: float = Field(default=10_000, gt=0, description="每笔金额")


@register_strategy
class MyStrategy(Strategy):
    name = "my_strategy"
    description = "一句话说明"
    Params = MyParams

    def on_start(self) -> None:            # 订阅行情、声明指标
        p = self.params
        self.ema = self.ctx.indicator("ema", p.symbol, p.timeframe, period=20)

    def on_session_open(self) -> None:     # 每天开始：重置当天的状态
        self.ctx.state["entered_today"] = False

    def on_bar(self, bar: Bar) -> None:    # 订阅周期的 bar 收盘时调用
        p = self.params
        if bar.symbol != p.symbol or bar.timeframe != p.timeframe or self.ema.value is None:
            return
        if self.ctx.state["entered_today"] or self.ctx.position(p.symbol).qty != 0:
            return
        if bar.close > self.ema.value and self.ema[-1] is not None and bar.open < self.ema[-1]:
            qty = int(p.notional // bar.close)
            self.ctx.buy(p.symbol, qty, reason=Reason("cross_ema", context={"ema": self.ema.value}),
                         take_profit=bar.close * 1.01, stop_loss=bar.close * 0.995)
            self.ctx.state["entered_today"] = True
```

**ctx 能做什么**
- 行情与指标：`subscribe(标的, 周期)`、`indicator(名字, 标的, 周期, **参数)`（`.value` 最新值，`[-1]` 上一根）、
  `history(标的, 周期, n)`、`today`（当天各时段时刻）。
- 下单（**必须带 Reason**，原因代码会出现在所有报告里）：`buy` / `sell`（市价、限价、止损、止损限价；
  `take_profit` + `stop_loss` 就是括号单）、`modify`（如移动止损）、`cancel`、`close_position`。
- 状态：`position`、`open_orders`、`now()`、`set_timer(名字, 时刻)` → `on_timer`。
- **需要跨重启保留的状态放 `ctx.state`**（只能放可 JSON 序列化的值），例如“今天是否已入场”。
- 记录：`log(...)`、`mark(标的, 文字)`（在图上打标记）。

**框架替你做的**（策略里不用写）：收盘前平仓、风控（单笔和持仓上限、亏损熔断、时间窗……）、
括号单的数量跟随、撮合与成本、手续费。

**规则**：不判断当前是回测还是实盘（`ctx` 也不提供）；不读写文件、不联网、不读系统时间；
不导入 `trader.brokers` / `trader.data` 等（测试会扫描检查）。

**验证流程（都在界面里）**
1. 保存 → “代码 → 重新加载”；回测表单的策略下拉框里会出现它，参数表单自动生成。
2. 先跑一个月：看概要、成本敏感性（成本加倍还赚不赚）、交易明细；点交易在图上复盘。
3. 回放：选一天，挂载策略，看它在盘中的实际行为。
4. 参数扫描：给参数填多个值，设样本外起始日；样本内好、样本外差的组合多半是过拟合。

## 3. 新图表

分三种情况：

| 想要的 | 怎么做 | 要改代码吗 |
| --- | --- | --- |
| 多看几个标的、周期，组合不同指标 | “窗口 → 新建图表”，每个图表单独设置；拖出来放到另一块屏幕；布局自动保存 | 不用 |
| 新的指标线、柱、标记 | 写一个新指标（第 1 节），用现有五种画法 | 不用（只写指标文件） |
| **新的绘图方式**：两条线之间填色、成交量分布（Volume Profile）、热力图、盘口/逐笔可视化、多标的叠加对比、相关性矩阵等 | 扩展界面：在 `OutputSpec` 增加画法，在 `src/trader/gui/assets/chart.js` 实现绘制；或者做一个新的面板 | 要，属于开发任务 |
| 一次性的分析图（分布、散点、热力图） | 在 JupyterLab 里用 notebook 接口取数，再用画图库画 | 不用；需要装画图库（如 plotly 或 matplotlib） |

图表用的是 TradingView 的开源库 Lightweight Charts；它能画的类型都可以加进来。
界面上的新功能（新面板、新按钮、新的联动）都属于开发任务，告诉 Claude 即可。

## 4. 让 Claude 来写

用中文描述清楚这几件事，效果最好：

1. **想法本身**：什么条件入场、出场、止损止盈；用什么周期和指标。
2. **参数**：哪些数值以后可能想调（会做成参数，界面上能改、能扫描）。
3. **边界**：每天最多几次、只做多还是可以做空、盘前盘后做不做、在哪些标的上用。
4. **怎么算成功**：例如“在 NVDA、TSLA 上 2025 年全年回测，成本加倍后仍然盈利”。

Claude 会：写代码 → 写测试 → 跑回测 → 截图或报告结果 → 说明哪些假设会影响结论。
例如：“写一个策略：开盘后 15 分钟，如果价格在 VWAP 之上且 5 分钟 RSI 低于 40，买入，止损放在当天最低价下方，
14:30 前平仓。每天最多一次，只做多，在 QQQ 和 SPY 上测 2025 年。”
