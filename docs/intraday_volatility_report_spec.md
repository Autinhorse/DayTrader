## 0. 目标

- 用户输入一组股票 / ETF 和一个日期范围，Notebook 计算每只证券在这段时间内的日内波动特征，输出一份报表
- 报表的核心是一组打分，回答："这段时间里，哪些证券日内波动足够大、来回震荡多、扣除成本后有可交易的空间"
- 同时给出按时段的波动分布，帮助判断一天中什么时候交易
- 所有阈值和权重都放在 Notebook 开头的参数单元格中

## 2. 参数和数据处理

### 2.1 参数单元格

| 参数 | 默认值 | 说明 |
|---|---|---|
| `tickers` | 用户输入 | 证券代码列表 |
| `benchmark_tickers` | `["SPY", "QQQ"]` | 参照证券，始终加入计算，在报表中单独标出 |
| `start_date`、`end_date` | 用户输入 | 分析区间 |
| `path_bar_size` | `5min` | 计算路程、效率比、自相关、方差比所用的 K 线周期 |
| `atr_days` | 21 | ATR 天数 |
| `atr_warmup_factor` | 3 | 某日之前至少要有 `atr_days` × 该倍数个交易日的数据，否则当天 ATR 为空 |
| `swing_thresholds_atr` | `[0.25, 0.5]` | 摆动识别阈值（ATR 倍数） |
| `vwap_cross_min_hold` | 3 | VWAP 穿越后至少保持的分钟数 |
| `cost_tiers_bps` | 价格 < $20：10；$20–$100：5；> $100：3 | 单边交易成本假设（基点），按当日开盘价分档 |
| `halt_gap_minutes` | 10 | 连续无成交超过该分钟数，标记 `possible_halt` |
| `exclude_early_close` | `True` | 汇总时是否剔除提前收盘日 |
| `min_dollar_vol` | $20M | 流动性提示阈值（只标记） |
| `min_tickers_for_scores` | 15 | 证券数少于此值时，报表提示以原始指标为主 |
| `score_weights` | 见第 5 节 | 打分权重 |
| `time_buckets_min` | 30 | 时段分析的时间桶长度 |

### 2.2 数据处理规则
- 只使用常规时段 9:30–16:00
- 日 K 线由 1 分钟 bar 汇总，不使用 Massive 日 K 线（后者包含盘前盘后）
- **缺失分钟不填充**。收益率类指标只在真实存在的 bar 之间计算；5 分钟 bar 用项目现有的汇总（整段无成交则该 5 分钟 bar 缺失）
- 每日记录 `missing_ratio` = 无成交的分钟数 / 当日应有分钟数，在汇总表中展示其中位数
- 连续无成交超过 `halt_gap_minutes` 的日子标记 `possible_halt = True`，**不剔除**，在报表开头列出所有被标记的日子
- 提前收盘日按 `exclude_early_close` 处理，被剔除的日子同样在报表开头列出

### 2.3 ATR 定义
- 真实波幅 TR = max(H, PC) − min(L, PC)，H、L 为常规时段最高、最低价，PC 为前一日常规时段收盘价
- ATR 使用 Wilder 平滑：ATR_t = (ATR_(t−1) × (n − 1) + TR_t) / n，n = `atr_days`，初始值为前 n 日 TR 的简单平均
- 计算某日指标时使用**前一交易日**的 ATR。为此需要从 `start_date` 往前多取 `atr_days` × `atr_warmup_factor` 个交易日的数据，使 Wilder 平滑收敛
- 本地数据从 2024-01-02 开始，新下载的证券历史可能更短：之前不足上述天数的日子 ATR 为空，**不参与汇总**，在报表开头列出（原因"ATR 预热数据不足"）

## 3. 每日指标（每只证券、每个交易日）

记号：O、H、L、C 为常规时段开高低收；PC 为前一日常规时段收盘价；ATR 为前一交易日的 ATR；q_t 为 `path_bar_size`（默认 5 分钟）bar 的收盘价。

**单位约定**：所有 `_pct` 字段均为百分数（1.0 表示 1%）；成本 bp 换算为百分数时除以 100（5bp = 0.05%）；所有 `_atr` 字段为 ATR 倍数。

### 3.1 幅度类

| 字段 | 计算 |
|---|---|
| `range_pct` | (H − L) / O × 100 |
| `range_atr` | (H − L) / ATR |
| `gap_atr` | (O − PC) / ATR |
| `rv_5min_pct` | sqrt(Σ r²) × 100，r 为相邻存在的 5 分钟 bar 收盘价之间的对数收益率 |
| `parkinson_pct` | (ln H − ln L) / sqrt(4 ln 2) × 100 |
| `dollar_vol` | Σ（1 分钟 vwap × 成交量） |
| `missing_ratio` | 见 2.2 |

### 3.2 形态类

| 字段 | 计算 | 含义 |
|---|---|---|
| `body_ratio` | \|C − O\| / (H − L) | **单边 / 震荡的主要判断依据**：接近 1 为单边，接近 0 为震荡 |
| `close_loc` | (C − L) / (H − L) | 收盘在当日区间中的位置 |
| `high_time`、`low_time` | 最高、最低价出现的时刻（距开盘分钟数） | 日内节奏 |

H = L 时，比例类指标为空值。

### 3.3 路程类（使用 `path_bar_size`，默认 5 分钟）

| 字段 | 计算 | 说明 |
|---|---|---|
| `path_range_ratio` | Σ\|q_t − q_(t−1)\| / (H − L) | 在当日区间内来回的程度 |
| `efficiency` | \|C − O\| / Σ\|q_t − q_(t−1)\| | 效率比 |
| `ac1` | 5 分钟收益率的一阶自相关 | 负值偏均值回归 |
| `vr_3` | 15 分钟收益率方差 / (3 × 5 分钟收益率方差) | 方差比；15 分钟收益率由 5 分钟 bar 汇总 |

这几项是辅助参考指标，**不进入震荡度打分**（原因：彼此高度相关，且在流动性差的证券上仍会受价差反弹影响）。实现时额外输出一组用 1 分钟 bar 计算的 `efficiency_1m`，供用户比较两种周期的差异。

### 3.4 摆动指标（核心）

对 `swing_thresholds_atr` 中的每个阈值 k 分别计算，字段名带后缀（如 `_k025`）。θ = k × ATR（价格单位），c 为当日成本（百分数）。

| 字段 | 计算 | 含义 |
|---|---|---|
| `swing_n` | 确认的摆动次数 | 起伏频度 |
| `swing_avg_atr`、`swing_avg_pct` | 平均摆动幅度 | 起伏幅度 |
| `swing_max_atr` | 最大摆动幅度 | |
| `swing_avg_minutes` | 平均每次摆动持续分钟数 | |
| `swing_total_pct` | Σ 摆动幅度（%） | **事后理论上限**，仅作参考 |
| `swing_capturable_pct` | Σ max(摆动幅度% − 2 × θ% − 2 × c, 0) | **估计可实际获取的波动**：转折点要在回撤 θ 后才能确认，入场和出场各损失约 θ，再扣除买卖两次成本 |

其中 θ% = θ / 摆动起点价格 × 100。

**摆动识别算法（ZigZag）**：
1. 使用 1 分钟 bar 的最高价和最低价逐分钟处理
2. **方向未定阶段**：同时记录开盘以来的最高价（及时刻）和最低价（及时刻）
   - 价格从开盘以来最低价上涨 ≥ θ：方向确定为向上，第一个转折点为该最低价
   - 价格从开盘以来最高价下跌 ≥ θ：方向确定为向下，第一个转折点为该最高价
3. **方向向上时**：出现新高则更新极值点；价格从极值点回落 ≥ θ，确认一次向上摆动（上一转折点 → 极值点），方向改为向下，新的极值点从该分钟最低价开始
4. **方向向下时**同理
5. **同一分钟内同时满足两个条件**（既创出新极值，又从极值回撤 ≥ θ；或方向未定时上下都满足）：读取该分钟的 1 秒 bar，按实际发生顺序处理。1 秒 bar 本身仍分不出先后（或没有 1 秒数据）时按保守规则：取确认摆动较少的顺序，一样多时按开盘价离最高价还是最低价近来定，并计数到 `ambiguous_minutes`。本地 1 分钟 bar 都由 1 秒数据汇总而来，所以这个计数主要来自 1 秒 bar 内部的歧义，通常很少
6. 收盘时尚未确认的最后一段不计入
7. 每次摆动保存起止时间、起止价格、幅度，形成明细表

### 3.5 其他

| 字段 | 计算 |
|---|---|
| `vwap_crosses` | 1 分钟收盘价穿越当日累计 VWAP，且穿越后连续 `vwap_cross_min_hold` 分钟（钟表时间）保持在新的一侧，计一次。缺失的分钟视为留在原来那一侧；距收盘不足保持时长的穿越不计；第一次站到某一侧不算穿越 |

### 3.6 时段指标

按 `time_buckets_min`（默认 30 分钟）切分，每个时间桶计算：已实现波动率（基于桶内 5 分钟收益率）、成交量占全天比例、该时间桶内确认的摆动次数（k = 0.25）。

## 4. 按证券汇总

- 每个每日指标计算：中位数、均值、25 分位数、75 分位数、标准差、有效天数
- **主要使用中位数**
- 单独列出振幅最大的 3 天和 `body_ratio` 最高的 3 天，方便检查是否为财报或重大消息日
- 时段指标：各时间桶的中位数
- **相对参照证券的比值**：对 `body_ratio`、`swing_n_k025`、`swing_capturable_pct_k025`、`range_atr`，计算该证券中位数 / SPY 中位数。用于跨批次比较，也为以后定分类阈值做准备

## 5. 打分

### 5.1 原则
- 分数 0–100，在本次输入的证券（加参照证券）中做百分位排名，是相对分数
- 报表同时展示原始指标中位数和相对 SPY 的比值
- 证券总数少于 `min_tickers_for_scores` 时，在排名表上方显示提示："证券数量较少，分数分档粗，请以原始指标为主"

### 5.2 分项得分

| 分项 | 组成（括号内为权重） | 回答的问题 |
|---|---|---|
| **活跃度** `score_activity` | `range_pct`（0.5）、`rv_5min_pct`（0.5） | 波动够不够大 |
| **震荡度** `score_rotation` | `swing_n_k025`（0.5）、1 − `body_ratio`（0.25）、`vwap_crosses`（0.25） | 是不是来回震荡 |
| **摆动价值** `score_swing_value` | `swing_capturable_pct_k025`（0.6）、`swing_avg_pct_k025`（0.4） | 扣除确认损失和成本后，有多少可获取的波动；单次摆动够不够大 |
| **稳定性** `score_consistency` | 见下文 | 是不是大多数日子都如此 |

**稳定性**：对每一天，用当天的 `swing_n_k025` 和 1 − `body_ratio` 在所有证券、所有交易日中算百分位，取平均得到"当日震荡分"。稳定性 = 当日震荡分 ≥ 50 的天数占比，再在证券之间做百分位排名。

各分项内部：组成指标先做百分位排名，再加权平均。

### 5.3 综合得分

日内适合度 `score_total` = 活跃度 × 0.30 + 震荡度 × 0.30 + 摆动价值 × 0.25 + 稳定性 × 0.15

权重可配置。成交额中位数低于 `min_dollar_vol` 的证券标记 `low_liquidity`，仍计算分数。

### 5.4 分类标签（第一版不实现）
- 第一版不输出震荡型 / 趋势型等标签
- 输出 `body_ratio`、`swing_n_k025`、`efficiency`、`vr_3` 的分布图（全部证券、全部交易日），以及相对 SPY 的比值分布
- 用户看过首批数据后，再确定标签规则和阈值（倾向于使用相对 SPY 的比值，而不是绝对阈值）

## 6. 报表内容

1. **参数和数据摘要**：证券列表、日期范围、有效交易日数；本地无数据的证券；被剔除的提前收盘日和 ATR 预热不足的日子；被标记 `possible_halt` 的日子；各证券 `missing_ratio` 中位数；`ambiguous_minutes` 总数（没有 1 秒数据时）
2. **成本假设说明**：明确写出"当前数据不含报价，交易成本为按价格分档的假设值"，并列出分档
3. **排名总表**：综合得分、四个分项、流动性提示，以及关键原始指标中位数（`range_pct`、`range_atr`、`body_ratio`、`swing_n_k025`、`swing_avg_pct_k025`、`swing_capturable_pct_k025`、`vwap_crosses`、`missing_ratio`、`dollar_vol`）和相对 SPY 的比值。参照证券用不同底色
4. **象限散点图**：横轴活跃度，纵轴震荡度，点大小为成交额
5. **分布对比**：前 10 名和参照证券的 `range_pct`、`body_ratio`、`swing_n_k025` 箱线图
6. **指标分布图**：第 5.4 节所列
7. **时段热力图**：行为证券（按综合得分排序），列为 30 分钟时间桶，颜色为该时段已实现波动率占全天的比例
8. **单只证券详情**（`detail_tickers`，默认综合得分前 3 名）：每日指标时间序列；一个典型交易日的 1 分钟价格图，叠加 VWAP 和摆动转折点，供人工检查
9. **指标说明**：各指标和分数的简要解释

## 8. 测试

- **摆动算法**：
  - 构造序列测试：正弦波（摆动次数和幅度可预期）、单边直线（0 次完整摆动）、随机游走
  - 方向未定阶段：构造"开盘先跌 0.2 ATR 再涨 0.5 ATR"的序列，确认第一段向上摆动从低点起算
  - 同一分钟冲突：构造 1 秒数据中先跌后涨和先涨后跌两种情况，确认处理结果不同且正确
- **效率比**：单边直线 = 1；往复后回到原点 ≈ 0
- **ATR**：用固定序列核对 Wilder 平滑结果；确认计算某日指标时只用到前一交易日及之前的数据
- **缺失处理**：构造含缺失分钟的数据，确认收益率不包含填充产生的 0
- **数据口径**：使用项目现有的 `trader data check-agg` 核对 1 分钟 bar 的汇总一致性
- **VWAP 穿越**：构造序列确认保持时长的判断
- **端到端**：合成数据跑完整流程，确认分数在 0–100、缺数据的证券和预热不足的日子被列出、图表和导出正常
- **人工检查**：报表第 8 部分的单日价格图
