## 修订说明

### v3.1（相对 v3，2026-10-16）

根据 v3 的运行结果（用户和网页版 Claude 的审阅意见）：

1. **打分默认阈值改为 0.25 ADR**：0.15 ADR 下可获取波动被高估（META 每天 3.6%，比它的振幅中位数还大），因为阈值越小摆动越多，而模型没有计入反应延迟和滑点。0.25 ADR 下每天约 5–12 次摆动，单次摆动（起点到终点）的持续时间中位数约 10–26 分钟
2. **识别摆动之前清洗数据**（新增 2.4 节）：删除坏数据时段清单里的时段，修正离群成交，再重算最高价、最低价、ADR 和摆动
3. **ADR 改用中位数**：均值会被大行情日拉高
4. **特殊日分两类**（3.7）："数据异常"（已清洗，列出供核对，可选整天剔除）和"行为特殊日"（数据没问题，只标记）
5. **新增转化效率** `conversion` = `swing_capturable_pct` 均值 / `adr_pct` 中位数；报表注明"可获取波动"是比较用的相对指数，不是能实际赚到的收益
6. notebook 默认打开多区间对比（2026-04~06），用来检查核心名单是否稳定

### v3（相对 v2）

根据第一次运行结果（2026-07-01 至 2026-09-30，22 只证券）发现的问题修订：

1. **ATR 改为 ADR**：v2 的 ATR 使用"真实波幅"，包含隔夜跳空，导致摆动阈值偏高，跳空大的证券被系统性低估（KORU 的阈值被放大到日内振幅的 2.3 倍）。评价"是否适合日内交易"只应使用常规时段数据，所有归一化改用常规时段的平均日内振幅 ADR
2. **摆动阈值降低**：v2 的 0.25 ATR 约为普通一天振幅的 30%，每天只能识别 3–5 次摆动；0.5 ATR 时所有证券的摆动次数中位数都是 0。改为 0.1 / 0.15 / 0.25 ADR，打分默认使用 0.15
3. **可获取波动的统计方式**：v2 只用中位数，许多证券为 0，结果由少数大行情日决定。新增均值和"可获取波动 > 0 的天数占比"，摆动价值分数改用这两项
4. **`*_vs_spy` 空值**：SPY 中位数为 0 时无法作分母。改用均值，并规定分母为 0 时的处理
5. **新增异常日检测**：v2 中 KORU 在 2026-09-21 振幅 5.9% 却识别出 24 次摆动，需要自动标记此类日子并人工核对
6. **新增"未确认的最后一段"字段**：收盘时未确认的最后一段走势单独记录，不计入摆动，但在报表中展示，避免趋势日被误读
7. **新增杠杆 ETF 与标的对照**：杠杆 ETF 的震荡形态与标的几乎相同，只是幅度放大，报表中并排对比，帮助二选一
8. **新增扩展时段参考小节**（不参与打分）：跳空拆解、盘前振幅、扩展时段成交占比
9. **复权输出一致性**：v2 的 `daily.csv` 中 KORU 在 2026-07-15 拆股前后价格未复权（各比例指标计算正确，但价格列不一致）。要求输出的价格列与计算口径一致
10. **新增多区间对比（可选）**：检验排名在不同时期是否稳定

**审阅补充（v3 定稿，2026-10-16，依据实际数据核对）**：

- **异常日阈值重新校准**（3.7）：v3 草稿的"摆动密度 > 4"是按 v2 的阈值估的；改用 0.15 ADR 后，正常日子的摆动密度中位数约 4.9，按 4 会把约七成的日子都标成异常。改为默认 12（约 99 分位）

- **最后一段**（3.4）：还没有任何转折点时（整天没确定方向），从开盘价起算；每个阈值各算一组
- **扩展时段取价**（7.1）：成交量过滤同样用于"盘前第一笔""盘后最后一笔"，不只用于最高 / 最低价，避免一笔几股的成交决定跳空拆解

## 0. 目标

- 用户输入一组股票 / ETF 和一个日期范围，Notebook 计算每只证券在这段时间内的**常规交易时段**波动特征，输出一份报表
- 核心是一组打分，回答："这段时间里，哪些证券日内波动足够大、来回震荡多、扣除成本后有可交易的空间"
- **原则：打分只使用常规时段（9:30–16:00）数据。** 隔夜跳空、盘前盘后数据只作为参考信息展示，不参与任何打分和归一化
- 所有阈值和权重都放在 Notebook 开头的参数单元格中

### 2.2 数据处理规则

与 v2 相同：
- 打分只使用常规时段 9:30–16:00
- 日 K 线由 1 分钟 bar 汇总
- 缺失分钟不填充；记录 `missing_ratio`
- 连续无成交超过 `halt_gap_minutes` 标记 `possible_halt`，不剔除，在报表开头列出
- 提前收盘日按 `exclude_early_close` 处理，剔除的日子在报表开头列出

### 2.3 ADR 定义（替代 v2 的 ATR）

- 每日常规时段振幅 R_t = H_t − L_t（H、L 为常规时段最高、最低价，**不涉及前一日收盘价**）
- ADR_t = 过去 `adr_days` 个交易日 R 的**中位数**（截至 t 日，含 t 日）。v3 为简单平均，会被大行情日拉高
- R 用清洗后（2.4）的最高价、最低价计算
- 计算某日指标时使用**前一交易日**的 ADR_(t−1)，没有前视偏差
- 从 `start_date` 往前多取 `adr_days` 个交易日（加上其间提前收盘日的天数）的数据
- 提前收盘日的 R 不计入 ADR 的计算（半天的振幅会拉低 ADR），也不占 `adr_days` 的名额
- 拆股日：R 使用复权价格计算，确保 ADR 连续
- 之前不足 `adr_days` 个可用交易日的日子，ADR 为空，不参与汇总，在报表开头列出（原因"ADR 数据不足"）

ATR 不再用于任何打分或归一化。如需展示跳空，用 ADR 倍数表示（`gap_adr`），仅作参考。

### 2.4 数据清洗（v3.1 新增，决策 0011）

在计算任何指标之前，对每天的常规时段数据：
1. **坏数据时段**：删除 `config/bad_data_windows.yaml` 中列出的时段（美东时间，可以指定证券或全部证券）里的 1 秒和 1 分钟 bar，当作没有成交的分钟。目前只有一条：2026-09-21 11:42–11:45，全部证券。发现新的坏数据时段就加进去
2. **离群成交**：1 秒 bar 的某个价格偏离前后各 30 根 1 秒 bar 收盘价中位数超过 `print_filter_adr` × ADR，视为离群：换成同一根 bar 里正常的价格；开盘价和收盘价都离群时删掉这根 bar。中位数窗口居中，开盘和收盘附近缩小成对称窗口，所以单边快速行情不会被误删，被修正的是"冒出去又马上回来"的价格。这里的 ADR 用原始振幅的中位数（之前不足 5 天时用当天的原始振幅），避免循环依赖
3. 用清洗后的 1 秒 bar 重算每根 1 分钟 bar 的开高低收（成交量、vwap 沿用原来的 1 分钟 bar），再汇总成 5 分钟 bar
4. 当天的最高价、最低价、收盘价、ADR、摆动（包括歧义分钟用的 1 秒数据）都用清洗后的数据
5. 每天记录 `fixed_prints`（修正或删除的 1 秒 bar 数）、`changed_minutes`（开高低收因此改变的 1 分钟 bar 数）、`window_minutes`（坏数据时段删掉的分钟数）、`filter_limit`（当天的离群阈值）

清洗只用于本报表，不改原始数据；图表、回测用的数据不变。扩展时段（第 7 节）不清洗。
开盘头几分钟密集的来回成交不是孤立的离群价，清洗不会去掉它们。

2026-07~09 的 22 只证券（0.25 ADR）：清洗让摆动次数减少 0–12%（KORU 12%，NVDA 9%，META 8%，MSFT 6%，AMZN 3%），可获取波动减少 0–17%（MSFT 17%，KORU 13%，AMZN 13%，META 12%）。

## 3. 每日指标（每只证券、每个交易日，仅常规时段）

记号：O、H、L、C 为常规时段开高低收；PC 为前一日常规时段收盘价；ADR 为前一交易日的 ADR；q_t 为 5 分钟 bar 收盘价。

**单位约定**：`_pct` 字段为百分数（1.0 表示 1%）；成本 bp 换算为百分数时除以 100；`_adr` 字段为 ADR 倍数。

### 3.1 幅度类

| 字段 | 计算 | 说明 |
|---|---|---|
| `range_pct` | (H − L) / O × 100 | |
| `range_adr` | (H − L) / ADR | **替代 v2 的 `range_atr`**。约等于 1 表示正常的一天 |
| `adr_pct` | ADR / O × 100 | 当日使用的 ADR 占价格的百分比 |
| `rv_5min_pct` | sqrt(Σ r²) × 100，r 为 5 分钟对数收益率 | |
| `parkinson_pct` | (ln H − ln L) / sqrt(4 ln 2) × 100 | |
| `dollar_vol` | Σ（1 分钟 vwap × 成交量） | |
| `missing_ratio` | 见 2.2 | |
| `gap_adr` | (O − PC) / ADR | **仅作参考，不参与打分** |

### 3.2 形态类

与 v2 相同：`body_ratio`、`close_loc`、`high_time`、`low_time`。

### 3.3 路程类

与 v2 相同：`path_range_ratio`、`efficiency`、`efficiency_1m`、`ac1`、`vr_3`。辅助参考，不进入打分。

### 3.4 摆动指标（核心）

对 `swing_thresholds_adr` 中的每个 k 分别计算，字段名带后缀（`_k010`、`_k015`、`_k025`）。**θ = k × ADR**，c 为当日单边成本（百分数）。

| 字段 | 计算 |
|---|---|
| `swing_n` | 确认的摆动次数 |
| `swing_avg_adr`、`swing_avg_pct` | 平均摆动幅度 |
| `swing_max_adr` | 最大摆动幅度 |
| `swing_avg_minutes` | 平均每次摆动持续分钟数 |
| `swing_total_pct` | Σ 摆动幅度（%），事后理论上限 |
| `swing_capturable_pct` | Σ max(摆动幅度% − 2 × θ% − 2 × c, 0)，θ% = θ / 摆动起点价格 × 100 |
| `last_leg_pct` | **新增**：收盘时尚未确认的最后一段（从最后一个转折点到收盘价）的幅度，带正负号。还没有任何转折点时从开盘价起算。不计入以上任何字段 |
| `last_leg_adr` | **新增**：同上，以 ADR 倍数表示 |

摆动识别算法与 v2 相同（方向未定阶段同时记录最高、最低价；同一分钟冲突用 1 秒数据判断；无 1 秒数据时保守处理并计入 `ambiguous_minutes`），只是 θ 改为 k × ADR。另外：
- 算法结束时，记录最后一个已确认的转折点，计算 `last_leg_pct`
- 摆动明细表中，最后一段以 `confirmed = False` 单独保存一行

### 3.7 特殊日：数据异常和行为特殊（v3 新增，v3.1 分成两类）

**数据异常日** `data_issue`（原因 `data_reason`）：落在坏数据时段，或清洗（2.4）时改动了 1 分钟 bar。已经在计算前处理掉；列出来并画核对图（灰色是清洗前的高低价），供人工确认清洗是否合理。`exclude_data_issue_days = True` 时整天不参与汇总（默认 `False`）。

**行为特殊日** `special_day`（原因 `special_reason`）：数据没问题，但当天走势特殊，只标记、不剔除。满足任一条件：
1. **摆动密度过高**：`swing_density` = Σ 摆动幅度（`score_k` 阈值）/ 当日振幅 > `anomaly_swing_density`（默认 7.5，0.25 ADR 下约为 99 分位；中位数约 2.9）。例如安静、在窄区间来回震荡的日子
2. **摆动次数远超平常**：`swing_n`（`score_k` 阈值）> 该证券区间内中位数 × `anomaly_swing_multiple`（默认 4），且 ≥ 10。财报日常满足这一条
3. **价格尖刺**：清洗后，开盘 `anomaly_skip_open_min`（默认 5）分钟以后仍有 1 分钟 bar 的最高价或最低价偏离前后各 5 根 1 分钟 bar 收盘价中位数超过 `anomaly_outlier_adr` × ADR（默认 0.5）。持续一分钟以上，多半是消息行情（例如 TLT 在经济数据发布时）

2026-07~09：数据异常日 96 个（其中 22 个是 2026-09-21 的坏数据时段），行为特殊日 28 个；2026-04~06：44 个和 50 个。

每类最多画 `review_plot_max` 张核对图（数据异常日按改动的分钟数从多到少），完整清单在报表开头和导出的 CSV 里。用 KORU 2026-09-21 作为测试样例。

## 4. 按证券汇总

- 每个每日指标计算：中位数、均值、25 分位数、75 分位数、标准差、有效天数
- **摆动类指标同时展示中位数和均值**；另外计算：
  - `capturable_days_ratio`：`swing_capturable_pct`（`score_k`）> 0 的天数占比
  - `conversion`（转化效率，v3.1）：`swing_capturable_pct` 均值 / `adr_pct` 中位数，即日内波动有多少能变成可交易的摆动。不参与打分
- **`swing_capturable_pct` 是比较用的相对指数**：没有计入反应延迟和滑点，不是能实际赚到的收益，报表中注明
- 单独列出振幅最大的 3 天、`body_ratio` 最高的 3 天、`|last_leg_adr|` 最大的 3 天
- 时段指标：各时间桶的中位数
- **相对参照证券的比值**（`*_vs_spy`）：
  - 对 `body_ratio`、`range_adr`、`swing_n`：用中位数之比
  - 对 `swing_capturable_pct`：用**均值**之比
  - 对 `capturable_days_ratio`：直接相除
  - 分母为 0 时输出空值，并在报表中注明原因；本次计算没有 SPY 时整组为空并注明

## 5. 打分

### 5.1 原则
与 v2 相同：0–100 的百分位排名，只有相对意义；证券少于 `min_tickers_for_scores` 时给出提示。**所有打分指标只来自常规时段。**

### 5.2 分项得分

| 分项 | 组成（括号内为权重） | 回答的问题 |
|---|---|---|
| **活跃度** `score_activity` | `range_pct` 中位数（0.5）、`rv_5min_pct` 中位数（0.5） | 波动够不够大 |
| **震荡度** `score_rotation` | `swing_n` 均值（0.5）、1 − `body_ratio` 中位数（0.25）、`vwap_crosses` 中位数（0.25） | 是不是来回震荡 |
| **摆动价值** `score_swing_value` | `swing_capturable_pct` 均值（0.4）、`capturable_days_ratio`（0.3）、`swing_avg_pct` 中位数（0.3） | 扣除确认损失和成本后有多少可获取的波动；是否大多数日子都有 |
| **稳定性** `score_consistency` | 同 v2 | 是不是大多数日子都震荡 |

摆动类指标均使用 `score_k` 对应的阈值。稳定性中的"当日震荡分"使用当天的 `swing_n` 和 1 − `body_ratio`。

### 5.3 综合得分

与 v2 相同：活跃度 × 0.30 + 震荡度 × 0.30 + 摆动价值 × 0.25 + 稳定性 × 0.15。

### 5.4 分类标签

第一版仍不实现。

## 7. 扩展时段参考指标（新增，不参与打分）

仅在 `include_extended_hours = True` 时计算。用途：理解每只证券的跳空来源和对消息的敏感程度，为以后的每日选股研究积累数据。

### 7.1 数据处理
- 盘后：16:00–20:00（前一交易日）；盘前：4:00–9:30（当日）。提前收盘日按交易日历
- 成交量低于 `eth_min_bar_volume` 的 1 分钟 bar，不参与取价（第一笔、最后一笔、最高价、最低价），但成交量照常累计
- 某时段没有任何满足条件的 bar 时，该时段指标为空
- 2026 年 12 月起如果新增夜盘时段，夜盘作为单独的一段处理（字段预留，第一版不实现；现在夜盘 bar 不参与任何字段）

### 7.2 每日字段

| 字段 | 计算 | 含义 |
|---|---|---|
| `gap_post_adr` | （前一日盘后最后成交价 − PC）/ ADR | 跳空中发生在前一日盘后的部分 |
| `gap_overnight_adr` | （当日盘前第一笔成交价 − 前一日盘后最后成交价）/ ADR | 无交易时段的变动 |
| `gap_pre_adr` | （O − 当日盘前第一笔成交价）/ ADR | 跳空中发生在当日盘前的部分 |
| `pm_range_adr` | 盘前最高价 − 最低价，除以 ADR | 盘前活跃程度 |
| `pm_high`、`pm_low` | 盘前最高价、最低价（复权） | 供以后研究"常规时段是否触及盘前高低点" |
| `eth_vol_share` | 当日盘前加盘后成交量 / （盘前 + 常规 + 盘后成交量） | 扩展时段成交占比 |

三段跳空之和等于 `gap_adr`（任一段缺失时，该日的拆解为空）。

### 7.3 汇总与展示
- 每只证券：各字段的中位数；三段跳空的绝对值占比（Σ|该段| / Σ|三段|，如"跳空中平均 60% 发生在盘前"）
- 报表中单独一张表展示，标题注明"仅供参考，不参与打分"
- 另外输出当日 `pm_range_adr` 与常规时段 `range_adr` 的散点图（全部证券、全部交易日）和相关系数（Pearson 和 Spearman），初步观察盘前活跃度能否预测当天振幅。严格的检验留给每日选股模块

## 9. 测试

v2 的全部测试保留，ATR 相关测试改为 ADR，另外新增：

- **ADR**：
  - 用固定序列核对 ADR 计算（中位数：一个大行情日不改变 ADR）
  - 确认 ADR 只使用前一交易日及之前的常规时段数据，且**不受前一日收盘价影响**（构造一个大跳空、但日内振幅不变的序列，ADR 应不变）
  - 提前收盘日不计入 ADR
  - 拆股日前后 ADR 连续
- **复权输出**：构造拆股数据，确认输出的价格列在拆股前后连续（KORU 2026-07-15 的实际数据已人工核对）
- **最后一段**：构造一个开盘后小幅震荡、之后单边下跌到收盘的序列，确认下跌段计入 `last_leg_pct` 而不计入 `swing_n`
- **特殊日**：构造数据确认两类日子的各个条件和原因；用 KORU 2026-09-21 实际数据测试（本地没有该数据时跳过）：坏数据时段被删除，清洗后摆动次数比不清洗少 10 次以上
- **数据清洗**：孤立的离群成交被修正，开收盘都离群的 1 秒 bar 被删除，单边快速行情（包括开盘、收盘附近）不被误删；1 分钟 bar 按清洗后的 1 秒 bar 重算，成交量不变；坏数据时段清单的读取和删除
- **扩展时段**：
  - 三段跳空之和等于 `gap_adr`
  - 小成交量 bar 不影响盘前最高价 / 最低价
- **阈值敏感性**：k 越小，`swing_n` 应单调不减（用大量随机游走做性质测试）
