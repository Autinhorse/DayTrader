# 功能二：每日选股（Daily Selection）

## 0. 目标

- 每个交易日在固定时刻，从功能一生成的观察股票池（200–500 只）中，选出当天重点关注的约 10 只
- 两种运行模式，共用同一套指标定义和选股逻辑：

| 模式 | 用途 | 数据来源 |
|---|---|---|
| 回测模式 | 研究、策略回测：对历史上每个交易日生成当日名单 | Massive 本地缓存的分钟 / 秒级 K 线 |
| 实盘模式 | 模拟盘和实盘：交易日当天定时运行 | IBKR API 实时数据 |

- 所有数值阈值都是默认值，放在配置文件中，可以按证券类别分别设置
- 输入：功能一的名单版本（回测时用当日有效的版本，实盘时用最新版本）
- 实现前请查阅 Massive 文档（https://massive.com/docs/llms.txt）和 IBKR TWS API 文档，确认接口和限制

## 1. 数据层设计

- 定义统一的数据接口，例如：
  - `get_bars(ticker, start, end, bar_size)`：返回包含盘前时段的 K 线
  - `get_prev_close(ticker, date)`
- 两个实现：`MassiveSource`（读本地缓存）和 `IBKRSource`（调用 IBKR API）
- 选股逻辑只依赖这个接口，不直接调用任何数据商的 API
- 历史均值（盘前平均成交量、开盘 5 分钟平均成交量、21 日 ATR）在两种模式下都直接读取功能一输出的字段，保证口径一致

### 1.1 IBKR 实盘的实现要点
- 推荐使用 Python 的 `ib_async` 库（`ib_insync` 的后续维护版本）或官方 `ibapi`
- 获取包含盘前数据的历史 K 线时，需要设置不限于常规交易时段（`useRTH=False`）
- IBKR 对同时订阅的实时行情数量和历史数据请求频率都有限制（具体数值以 IBKR 文档和账户设置为准），无法在几分钟内逐只获取 500 只股票的数据。因此实盘模式采用**两步法**：
  1. **粗筛**：使用 IBKR 的市场扫描器（scanner，如涨跌幅榜、盘前涨跌幅、成交量异动等扫描类型），获取当时全市场的异动股票，与观察股票池取交集
  2. **精算**：只对交集中的股票（预计几十只以内）加上手工名单中 `pin_daily` 为 true 的证券，请求分钟 K 线，按第 2 节计算完整指标
- 请求要做限速控制和失败重试；某只股票取数失败时记录警告并跳过，不中断整体运行
- 实盘需要在 IBKR 账户中订阅相应的美股实时行情数据
- 由于粗筛方法不同，实盘名单可能与回测逻辑下的名单略有差异。记录每天的粗筛结果和最终结果，方便日后对比

## 2. 运行时点和指标

两个时点，参数可配置（美东时间）：

| 时点 | 默认时间 | 使用数据 | 输出 |
|---|---|---|---|
| 盘前筛选 | 9:20 | 当日 4:00–9:20 盘前数据 + 历史数据 | 候选名单（约 20 只） |
| 开盘确认 | 9:35 | 加上 9:30–9:35 数据 | 最终名单（约 10 只） |

- 回测时严格遵守时点：9:20 的筛选只能用 9:20 之前的数据；最终名单中的证券，策略**只能从 9:35 之后**开始交易

### 2.1 指标定义

| 指标 | 定义 |
|---|---|
| `gap_pct` | 筛选时刻的最新成交价 / 前一日收盘价 − 1 |
| `gap_atr` | 跳空幅度 / 前一日的 21 日 ATR（跳空占日常波动的倍数，不同证券之间可比） |
| `pm_dollar_vol` | 当日 4:00 至筛选时刻的盘前成交额 |
| `pm_rvol` | 当日盘前成交量 / 功能一输出的历史盘前平均成交量（按相同时间段折算） |
| `open_rvol` | 当日 9:30–9:35 成交量 / 功能一输出的历史开盘 5 分钟平均成交量 |
| `open_range_atr` | 9:30–9:35 的最高价减最低价，除以 21 日 ATR |
| `rel_gap_vs_spy` | 本证券 `gap_pct` 减去 SPY 的 `gap_pct`（剔除大盘整体跳空的影响） |
| `has_earnings` | 前一日盘后或当日盘前是否发布财报（如能获得，否则为空） |

- 盘前没有成交的证券，盘前指标为空，不参与盘前排名，但仍参与开盘确认（见 4.2）

## 3. 按类别的选股参数

不同类别的证券，日内异动的含义不同。比如个股跳空多来自公司消息，宽基 ETF 跳空反映整体市场，杠杆 ETF 的走势基本由标的决定。因此每个类别单独设置：

| 类别 | 参与竞选 | 最多入选 | 最低盘前成交额 | 跳空指标 |
|---|---|---|---|---|
| `stock` | 是 | 不限（受行业约束） | $1M | `gap_atr` |
| `adr` | 是 | 3 | $1M | `gap_atr` |
| `etf_broad` | 否（作为参照固定输出） | — | — | — |
| `etf_sector` | 是 | 2 | $2M | `rel_gap_vs_spy` 换算成 ATR 倍数 |
| `etf_macro` | 是 | 2 | $2M | `gap_atr` |
| `etf_leveraged` | 是 | 2 | $5M | `gap_atr` |
| `etp_volatility` | 是 | 1 | $5M | `gap_atr` |
| `etn`、`etf_other` | 是 | 1 | $2M | `gap_atr` |

- 以上全部为配置参数
- 第 4、5 节中的门槛和权重也可以按类别覆盖默认值

## 4. 筛选流程

### 4.1 盘前筛选（9:20）

**门槛**（满足任一即进入候选，且盘前成交额达到本类别最低值）：
- |跳空指标| ≥ 0.5 倍 ATR
- `pm_rvol` ≥ 3
- `has_earnings` 为真

**排序**：
- 综合分数 = |跳空指标| 的百分位排名 × 0.5 + `pm_rvol` 的百分位排名 × 0.5（权重可配置）
- 百分位排名在当日所有满足门槛的证券之间计算
- 取前 `n_candidates` 只（默认 20）

### 4.2 开盘确认（9:35）

**盘前候选的确认**：保留 `open_rvol` ≥ 2 的证券

**开盘异动补充**：观察股票池中**不在候选名单里**的证券，如果 `open_rvol` ≥ 4 且 `open_range_atr` ≥ 0.3，也加入（盘前没有消息、开盘突然放量的情况）。实盘模式下，这一步通过 IBKR 扫描器的成交量异动类扫描粗筛

**最终排序**：
- 综合分数 = `open_rvol` 百分位排名 × 0.5 + |跳空指标| 百分位排名 × 0.3 + `pm_rvol` 百分位排名 × 0.2（权重可配置；缺失值按 0 处理）
- 按分数从高到低依次选取，目标数量 `n_final`（默认 10），同时满足以下约束（可关闭）：
  - 每个类别不超过第 3 节的入选上限
  - 个股同一行业最多 `max_per_sector` 只（默认 3）
  - 杠杆 ETF 与其标的（如 TQQQ 与 QQQ、SOXL 与 SMH）不同时入选，保留分数较高的一个；标的关系来自功能一的 `underlying` 字段
- 满足条件的证券不足 `n_final` 时，**不强行补足**，输出实际数量

### 4.3 固定输出（pinned）
- 手工名单中 `pin_daily` 为 true 的证券（默认包括 SPY、QQQ、IWM、DIA），以及 `etf_broad` 类别中的证券，每天固定输出，单独标记为 `pinned`
- 它们**不占用** `n_final` 名额
- 同样计算所有指标，方便查看当天大盘状态
- 手工名单中 `pin_daily` 为 false 的证券，和自动筛选部分一样正常参与竞选

## 5. 输出

每个交易日输出（Parquet，按日期分区）：

| 字段 | 说明 |
|---|---|
| `date` | 交易日 |
| `mode` | `backtest` / `live` |
| `ticker` | |
| `category` | 继承自功能一 |
| `stage` | `premarket_candidate` / `final` / `pinned` |
| `source` | `premarket` / `open_surge` / `pinned` |
| `rank`、`score` | |
| `gap_pct`、`gap_atr`、`rel_gap_vs_spy`、`pm_dollar_vol`、`pm_rvol`、`open_rvol`、`open_range_atr` | |
| `has_earnings` | |
| `sector`、`is_manual`、`underlying` | 继承自功能一 |
| `tradable_from` | 可开始交易的时间（默认 9:35） |
| `watchlist_version` | 使用的功能一名单版本 |

实盘模式另外：
- 在终端打印简洁表格：代码、类别、跳空、盘前倍数、开盘倍数、行业、是否财报
- 可选：通过 IBKR API 把最终名单和 pinned 证券写入 TWS 的一个自选列表（如果 API 支持，否则导出 CSV 供手工导入）
- 保存当天的粗筛结果，用于和回测逻辑对比

## 6. 测试与分析

- **前视偏差测试**：回测某日时，删除筛选时刻之后的所有数据，结果必须一致
- **口径一致性测试**：对最近若干个交易日，分别用 Massive 数据和 IBKR 数据计算同一批证券的指标，比较差异（成交量口径可能因数据源不同略有差别，记录差异幅度）
- **统计报告**（回测模式下生成）：
  - 每日入选数量的分布，各类别入选数量
  - 入选证券当日 9:35–16:00 的振幅（以 ATR 为单位）和成交量，与未入选证券对比，检验选股是否真的选出了更活跃的证券
  - 按类别、`source`、是否财报、跳空方向分组统计

## 7. 后续扩展（第一版不实现，预留接口）

- 接入新闻数据作为催化剂标记
- 结合 Volume Profile：标记盘前价格位于前一日价值区之内还是之外，以及与前一日 POC、VAH、VAL 的距离（以 ATR 为单位）

## 8. 配置参数汇总

- 通用：`premarket_time`、`confirm_time`、`n_candidates`、`n_final`、`max_per_sector`、`dedupe_leveraged`、`premarket_score_weights`、`final_score_weights`、`data_source`（massive / ibkr）
- 门槛：`min_gap_atr`、`min_pm_rvol`、`min_open_rvol`、`surge_open_rvol`、`surge_open_range_atr`
- 按类别：是否参与竞选、最多入选数量、最低盘前成交额、跳空指标类型，以及对通用门槛和权重的覆盖值
- IBKR：连接参数（主机、端口、client id）、扫描器类型列表、请求限速参数、重试次数
