# IBKR 模拟账户手工清单（阶段 6 验收）

自动化测试只用假的 IB 客户端；下面这些必须在真实的 IBKR 模拟账户上做一遍，才算接口、订单流、恢复和对账真正可用。
每项做完在方框里打勾，记下日期和结果。全部只针对**模拟账户**（账户号 DU 开头，端口 4002）。

## 准备（每次）

- [ ] IB Gateway 以**模拟账户**登录，API 设置：端口 4002，**取消勾选 Read-Only API**。
- [ ] 手机 App 等其他地方**没有登录实盘账户**（否则行情报 10189）。
- [ ] 本地数据已更新到上一个交易日：`uv run trader data update`
- [ ] 不要同时运行 local_paper 和 broker_paper（两个进程各订阅 5 个逐笔，会超过账户额度）。

## 界面

- [ ] 双击 `run_broker_paper.bat`：出现引擎窗口和实盘版界面（橙色横幅“IBKR 模拟账户”），界面显示“引擎正常 已连接 IB”
- [ ] 关掉界面，引擎窗口继续运行；`uv run trader-live-ui --profile broker_paper` 重新打开，状态和告警都在
- [ ] 关掉引擎窗口：界面在 5 秒内显示“引擎无响应”

## A. 自动冒烟（常规时段 9:30–16:00）

`uv run python tools/paper_smoke.py`，每张单只有 1 股 SPY，结束时持仓恢复原状。

- [x] 1 限价单：券商接受 → 改价确认 → 撤单确认
- [x] 2 市价买 1 股：成交、手续费到达、对账一致
- [x] 3 原生括号单：入场成交，止盈止损两张单在券商端工作（在 TWS 或手机 App 的模拟账户里能看到，订单备注是我们的订单号）
- [x] 4 人工平仓：先撤保护单、等撤单确认、再卖出，持仓归零，没有变成空头
- [x] 5 最终对账一致

## B. 策略运行

- [ ] `uv run trader-live --profile broker_paper --start-strategy`：启动检查全部通过，策略开启前处于暂停
- [ ] 策略下的单在 TWS/手机里能看到，带括号单保护；`runs/live/<日期>/broker_paper/status.json` 与券商一致
- [ ] 15:55 收盘前自动平仓：先撤单再平仓，最终空仓

## C. 故障与恢复

- [ ] **Gateway 断开**：运行中关闭 IB Gateway → 窗口出现 CONNECTION_LOST，策略暂停；重新登录 Gateway →
      自动重连、补数，提示“策略保持暂停，需要人工恢复”
- [ ] **发单途中断线**：下单后立即断开 Gateway → 订单变为“未知”，重连后查询得到真实状态，没有重复下单
- [ ] **本机进程崩溃**：括号单入场成交后，直接关闭 trader-live 窗口 → 保护单仍在券商端（TWS/手机可见）→
      重新启动 → 从日志恢复订单和持仓，对账一致，策略暂停
- [ ] **对账不一致**：在手机 App 的模拟账户里手动买 1 股清单内的股票 → 2 分钟内出现 RECONCILE_MISMATCH，策略暂停；
      在界面上“按券商持仓重置”后对账一致
