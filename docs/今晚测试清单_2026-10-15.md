## 第 0 步　准备（20:30 前后，开盘前随时可以做）

- [ ] 0.1 电脑设置成**不睡眠**：设置 → 系统 → 电源 → “屏幕和睡眠”里“插电时使计算机进入睡眠”选“从不”（今晚程序要跑到明早）
- [ ] 0.2 手机上的 IBKR App **退出实盘账户**（否则行情会报错 10189）。手机可以登录**模拟账户**，后面要用
- [ ] 0.3 打开 IB Gateway，用**模拟账户**登录。Configure → Settings → API：端口 4002，**不勾选** Read-Only API
- [ ] 0.4 同一个设置窗口里看 “Lock and Exit” 的自动重启时间：不要落在 21:30～04:00 之间（比如改成 11:45 AM）
- [ ] 0.5 更新本地数据：在项目文件夹的地址栏输入 `cmd` 回车打开命令行，运行 `uv run trader data update`，等它结束
- [ ] 0.6 用记事本打开 `config\broker_paper.yaml`，找到这三行：

  ```yaml
  strategy:
    name: orb_breakout
    params: {symbol: NVDA}
  ```

  在下面**加一行**（前面两个空格，和 `params` 对齐），保存：


## 第 2 步　故障测试（21:30～22:00，开盘后前半小时）

这半小时策略在记录开盘区间，**不会**出信号，正好用来做故障测试。每项都用**手动下单**，买 1 股 SPY。
做不完没关系，没做的项目放到第 4 步之后再做。

### 2A　手动括号单 + 程序崩溃（最重要）

- [ ] 2A.1 界面右上“手动下单”：标的 `SPY`，BUY，数量 `1`，MKT；括号单止盈填“现价 + 20”，止损填“现价 − 20”；点“下单”并确认
- [ ] 2A.2 “持仓”里出现 SPY 1 股；在手机 App（模拟账户）或 TWS 里能看到**两张保护单**（一张限价卖、一张止损卖）
- [ ] 2A.3 直接**关掉引擎窗口**（模拟程序崩溃）→ 手机里两张保护单**还在**
- [ ] 2A.4 双击 `run_broker_paper.bat` 重新启动 → 告警里有“从日志恢复 … 张订单”，持仓 SPY 1 股，挂单里有两张保护单，没有对账不一致

### 2B　断开 Gateway

- [ ] 2B.1 关掉 IB Gateway → 界面出现 `CONNECTION_LOST`（红字），右下角弹通知
- [ ] 2B.2 重新打开 Gateway、用模拟账户登录 → 一两分钟内告警出现“已重连并补数；策略保持暂停，需要人工恢复”，界面恢复绿色

### 2C　对账不一致

- [ ] 2C.1 在手机 App 的模拟账户里**手动买 1 股 SPY**
- [ ] 2C.2 2 分钟内界面出现 `RECONCILE_MISMATCH`（本地 1 股，券商 2 股）
- [ ] 2C.3 点“按券商持仓重置”并确认 → 再点“立即对账” → 显示“对账一致”

### 2D　收拾干净

- [ ] 2D.1 点“全部平仓”并确认 → 先撤掉保护单，再卖出，持仓清空，手机里也空仓、没有挂单
- [ ] （可以跳过）2E 发单途中断线：下单后马上关 Gateway。手动很难卡准时间，自动测试已覆盖

## 第 4 步　等策略信号并确认（22:05 以后，什么时候来不一定）

策略看 NVDA：价格突破 21:30～22:00 的高点或低点时出信号，**一天最多一次**，也可能整晚都不来。
信号来了只有 **15 秒**，人尽量在电脑旁边。

- [ ] 4.1 信号来时：界面自动跳到最前、响一声、右下角弹通知
- [ ] 4.2 “待确认信号”变成红框，里面一行：NVDA、方向、数量、止盈、止损、预估金额（约 1 万美元）、指标值，剩余秒数在倒数
- [ ] 4.3 这时手机/TWS 里**还没有**这张单
- [ ] 4.4 点绿色的“确认（发出订单）”→ 手机里出现入场单，成交后有两张保护单；界面下方显示“确认 1”

**如果没赶上 15 秒**：信号会消失，告警里有“超时未确认，已作废”，手机里没有订单——这正好测了“超时”，在下面打勾，今晚这个策略就不会再下单了。

- [ ] 4.5（没赶上时）超时后信号消失、券商没有收到订单

**如果到 01:00 还没来信号**：不用再等，直接去第 5 步。
