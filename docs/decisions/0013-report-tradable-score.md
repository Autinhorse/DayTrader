# 0013 日内波动报表 v3.3：可交易性评分作主排序、每日转化效率中位数、合并区间

日期：2026-10-16　状态：已采纳　依据：网页版 Claude 对 v3.2 结果的审阅意见（用户转来）

## 背景

v3.2 的综合得分里，活跃度（振幅）、震荡度（摆动次数、1 − body_ratio、VWAP 穿越次数）占 60%，它们和"扣除确认损失和成本后
能拿到多少"没有直接关系。2026-07~09 剔除开盘 5 分钟后，GLD 排第 6、AMZN 排第 3，但两者每天的可获取波动只有约 0.45% 和 0.58%。
稳定性（当日震荡分 ≥ 50 的天数占比）挤在 0.30–0.59，5 只证券并列 0.516，换算成分数跳动很大。单季排名噪音也大
（两季名次相关 0.56）。

## 结论

1. 新增**可交易性评分**作主排序：可获取波动均值（绝对值）0.4、转化效率 0.3、每日转化效率中位数 0.3，各项先做百分位排名。
   原综合得分和四个分项保留作参考。阈值敏感性、开盘剔除对照、多区间对比都改按可交易性评分排名。
2. **稳定性 = 每日转化效率的中位数**（连续值）。它同时是可交易性评分的一项，所以原综合得分里的稳定性分项也随之改变。
3. **合并区间**：`merge_periods` 把几个区间合成一个样本。实现上连续读取最早到最晚的数据再筛选，ADR、前收盘等跨日量和连续计算一致
   （测试覆盖）。连续的区间（如 4–9 月）直接用 start/end 即可，两种方式结果相同。
4. notebook 默认改为 2026-04-01 ~ 2026-09-30。
