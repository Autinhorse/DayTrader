# Volume Profile 模块设计规范 v1

## 0. 目标

- 根据本地已有的 1 秒 / 1 分钟 K 线，生成各种时间窗口的 Volume Profile（成交量按价格分布），并提取关键价位：POC、价值区（VAH / VAL）、高成交量节点（HVN）、低成交量节点（LVN）
- 输出供三处使用：
  1. **研究**：Notebook 中可视化、统计关键价位的作用
  2. **每日选股**：盘前价格相对前一日价值区的位置
  3. **策略回测**：在 META、AMD、NVDA 等证券上回测基于价值区的日内策略
- **时点正确是第一要求**：任何时刻 t 的 Profile 只能使用 t 之前的数据
- 所有参数放在配置中，第一版的默认值见各节

## 1. 与本项目的对接

| 事项 | 做法 |
|---|---|
| 数据读取 | 使用现有 `load_bars(sym, "1s" / "1m", start, end, session=..., adjusted=True)`。默认用 **1 秒 bar**（本地已有的证券），没有 1 秒数据时退回 1 分钟 bar，并在输出中标记 `source_bar` |
| 数据清洗 | 复用日内波动报表的清洗逻辑：`config/bad_data_windows.yaml` 坏数据时段删除；1 秒离群成交修正（`print_filter_adr`）。清洗后的数据才用于计算 |
| ADR | 复用报表中的 ADR 定义（过去 21 日常规时段振幅中位数，用前一交易日的值），用于确定价格格子大小 |
| 交易日历 | 使用现有交易日历（含 `early_close`） |
| 复权 | 见 2.4 |
| 代码位置 | 建议 `src/trader/profile/`（或按项目分层规则放置），只依赖数据层；按项目约定先写决策记录 |
| 依赖 | 不新增依赖（numpy / pandas / matplotlib 已有） |

## 2. 计算方法

### 2.1 成交量分配到价格格子

每根 bar 的成交量按以下方法之一分配到它覆盖的价格格子（参数 `distribution`）：

| 方法 | 说明 | 默认 |
|---|---|---|
| `uniform` | 成交量平均分配到 [low, high] 覆盖的所有格子 | **默认** |
| `close` | 全部归到收盘价所在格子 | |
| `typical` | 全部归到 (H + L + C) / 3 所在格子 | |
| `vwap` | 全部归到该 bar 的 vwap 所在格子（bar 有 vwap 字段时） | |

- 用 1 秒 bar 时，绝大多数 bar 的高低价只差 0–2 个最小价位，四种方法结果几乎相同；用 1 分钟 bar 时差别会大一些
- 实现一个对比函数：同一天用 `uniform` 和 `close` 各算一次，输出 POC、VAH、VAL 的差异（以 ADR 倍数计），用于确认方法不是瓶颈

### 2.2 价格格子（bin）

- **底层统一按最小价位 $0.01 存储**（"细网格"），所有更粗的格子都由细网格合并得到。这样只需计算一次，之后可以任意改变格子大小，复合 Profile 也只是细网格相加
- 分析和提取关键价位时使用的格子大小（参数 `bin_mode`）：

| 模式 | 计算 | 默认 |
|---|---|---|
| `adr` | 格子 = ADR × `bin_adr_frac`，向上取整到 $0.01 的整数倍 | **默认**，`bin_adr_frac` = 0.02（一天约 50 个格子） |
| `pct` | 格子 = 价格 × `bin_pct` | `bin_pct` = 0.0005 |
| `fixed` | 固定金额，如 $0.05 | |

- 复合 Profile（多天）使用**最后一天**的格子大小

### 2.3 成交量的取舍

| 参数 | 默认 | 说明 |
|---|---|---|
| `session` | `rth` | `rth`（9:30–16:00）、`pre`（4:00–9:30）、`post`（16:00–20:00）、`eth`（盘前加盘后）。将来如有夜盘，增加 `overnight` |
| `exclude_open_cross` | `False` | 剔除 9:30:00 那一秒的成交（开盘集合竞价通常集中在这一秒） |
| `exclude_close_cross` | `True` | 剔除 15:59:59–16:00:00 的成交（收盘集合竞价）。收盘竞价量很大且集中在一个价格，不剔除会把 POC 拉向收盘价 |
| `min_bar_volume` | 0 | 扩展时段建议设 100：成交量过小的 bar 不参与 |

- 注意：K 线数据无法区分具体成交条件（零股、均价成交等），只能通过上述时间窗口粗略剔除竞价。将来如订阅逐笔成交数据，可按成交条件精确剔除（预留接口）
- 提前收盘日：收盘竞价时间按实际收盘时间处理

### 2.4 复权

- 每日 Profile 用**当天的实际价格**存储在细网格上，同时记录当天的复权系数
- 构建跨越拆股日的复合 Profile 时，先把各天的价格乘以复权系数换算到同一口径，再重新分配到细网格
- 测试：KORU 2026-07-15（20 比 1 拆股）前后的复合 Profile 连续

## 3. 关键价位的提取

### 3.1 POC
- 成交量最大的格子的中间价
- 有多个格子并列时，取最接近 Profile 成交量加权中心的那个

### 3.2 价值区（VAH / VAL）
- 默认包含 70% 的成交量（参数 `value_area_pct`）
- 算法（经典做法）：
  1. 从 POC 开始
  2. 比较上方相邻两个格子的成交量之和，与下方相邻两个格子之和
  3. 把较大的一侧（两个格子）纳入价值区；相等时纳入靠近上一日收盘价的一侧
  4. 重复，直到价值区成交量 ≥ 总量的 70%
- 输出 VAH = 价值区最高格子的上沿，VAL = 最低格子的下沿

### 3.3 HVN / LVN
- 先对分布做平滑（参数 `smooth_bins`，默认 3 格移动平均）
- **HVN**：局部峰值，且成交量 ≥ 分布最大值的 `hvn_min_frac`（默认 0.3）
- **LVN**：两个 HVN 之间的局部谷值，且成交量 ≤ 两侧较低峰值的 `lvn_max_frac`（默认 0.3）
- 输出每个节点的价格和"显著性"（峰或谷相对两侧的成交量比值）

### 3.4 形态指标（只作描述，第一版不做分类）

| 字段 | 计算 | 含义 |
|---|---|---|
| `va_width_adr` | (VAH − VAL) / ADR | 价值区宽度 |
| `poc_position` | (POC − Profile 最低价) / (最高价 − 最低价) | POC 在区间中的位置：偏上为 P 形，偏下为 b 形 |
| `n_hvn` | HVN 个数 | ≥ 2 且中间有显著 LVN 时，为双峰分布 |
| `volume_skew` | 成交量分布的偏度 | |

## 4. 时间窗口（Profile 类型）

所有类型共用第 2、3 节的计算方法，区别只在"取哪些 bar"。

| 类型代码 | 窗口 | 用途 | 第一版 |
|---|---|---|---|
| `daily` | 某一天的常规时段 | 最基础的单元；第二天作为"前一日 Profile"使用 | ✅ |
| `developing` | 当天开盘到时刻 t（滚动更新） | 当天价值区如何形成、POC 往哪里移动；回测中唯一合法的"当日 Profile" | ✅ |
| `composite` | 前 N 个交易日合并（N = 3、5、10、20） | 更大级别的价值区和 HVN / LVN | ✅ |
| `decay` | 历史所有日子按时间衰减加权，半衰期 H 天（默认 3、5） | 不必纠结 N 取多少；近期占主导，远期逐渐淡出 | ✅ |
| `anchored` | 从某个锚点日期（或时刻）到当前 | 财报跳空、突破等事件后，定价基础改变 | ✅（锚点手工指定，或用跳空 ≥ 1 ADR 的日子自动生成） |
| `turnover` | 往回累计，直到成交量达到流通股本的 X%（默认 50%、100%） | 用换手衡量"当前持有者的成本分布" | 第二版（需要流通股本数据） |
| `premarket` | 当天 4:00–9:30 | 开盘前参考；与前一日价值区比较 | ✅ |
| `postmarket` | 前一日 16:00–20:00 | 消息后的初步定价 | ✅ |
| `intraday_split` | 当天按时段拆分，如开盘 30 分钟、上午、下午 | 观察价值区在一天中的迁移 | 第二版 |
| `tpo` | 不按成交量，按时间：每个 30 分钟时段在某价格出现过就计 1 次（Market Profile） | 和成交量 Profile 对照；成交量稀少时更稳健 | 第二版 |

### 4.1 时点规则（必须遵守）

| 类型 | 在交易日 T、时刻 t 可以使用的数据 |
|---|---|
| `daily`（作为前一日参考） | T−1 及之前的完整交易日 |
| `developing` | T 日开盘到 t（不含 t 之后的任何 bar） |
| `composite` / `decay` | T−1 及之前的完整交易日；如需"包含当天"，必须用 `composite + developing` 的组合，并只取到 t |
| `anchored` | 从锚点到 t |
| `premarket` | T 日 4:00 到 min(t, 9:30) |
| `postmarket` | T−1 日 16:00–20:00 |

### 4.2 `developing` 的实现
- 以 1 分钟为步长更新（参数 `developing_step`），每一步输出：时刻、dPOC、dVAH、dVAL、累计成交量
- 增量计算：每分钟只把新 bar 加到细网格上，不要每次重算全天
- 前 `developing_min_minutes`（默认 15）分钟的价值区不稳定，输出时标记 `stable = False`

### 4.3 未回测的 POC（naked POC）
- 对每个 `daily` POC，记录之后哪一天（哪个时刻）价格首次触及它
- 在 T 日开盘时，列出过去 `naked_lookback`（默认 20）个交易日中尚未被触及的 POC，作为潜在目标位

## 5. 输出

### 5.1 存储
- **每日细网格 Profile**（Parquet，按证券 / 日期分区）：`symbol`、`date`、`session`、`price_cents`、`volume`、`adj_factor`、`source_bar`
- 这是唯一需要从 K 线计算的部分，其余都由它派生。增量更新：只计算新日期

### 5.2 关键价位表（`levels`）
每行一个（证券, 日期, Profile 类型, 参数）：

| 字段 | 说明 |
|---|---|
| `symbol`、`date`、`profile_type`、`params` | 如 `composite`、`{"n": 5}` |
| `as_of` | 计算所使用数据的截止时刻（时点检查用） |
| `bin_size` | 格子大小（$） |
| `poc`、`vah`、`val` | |
| `profile_high`、`profile_low`、`total_volume` | |
| `hvn`、`lvn` | 价格列表 |
| `va_width_adr`、`poc_position`、`n_hvn`、`volume_skew` | 形态指标 |

### 5.3 Developing 序列（`developing`）
每行：`symbol`、`date`、`time`、`dpoc`、`dvah`、`dval`、`cum_volume`、`stable`

### 5.4 Naked POC 表
`symbol`、`poc_date`、`poc`、`touched_date`、`touched_time`（未触及时为空）

### 5.5 API
提供简单的函数接口，供每日选股和回测调用，例如：
- `get_levels(symbol, date, profile_type, **params)` → 当天开盘前可用的关键价位
- `get_developing(symbol, date, until_time)` → 截至某时刻的当日价位
- `get_profile(symbol, start, end, bin_size, ...)` → 任意区间的分布（研究用）

## 6. Notebook（`Volume Profile.ipynb`）

参数单元格：证券、日期、Profile 类型和参数、格子大小。展示：
1. **单日图**：左边 1 分钟 K 线（或价格线）加 VWAP，右边横向成交量分布；画出前一日 POC / VAH / VAL、5 日复合价值区、developing POC 的轨迹、盘前高低点
2. **多窗口对比**：同一天的前一日、5 日、20 日、衰减（H = 3）Profile 并排，看关键价位是否重合
3. **方法敏感性**：`uniform` 与 `close`、1 秒与 1 分钟 bar 的 POC / VA 差异分布（ADR 倍数）
4. **格子大小敏感性**：`bin_adr_frac` = 0.01 / 0.02 / 0.05 时的 POC / VA 差异
5. **形态指标分布**：各证券的 `va_width_adr`、`poc_position` 分布

## 7. 测试

- **守恒**：分配后的总成交量等于原始成交量（剔除的竞价部分单独记账）
- **价值区**：价值区内成交量 ≥ 70%，且是满足条件的连续区间
- **构造数据**：
  - 单峰正态分布 → POC 在中心，VA 约 ±1 标准差
  - 双峰分布 → `n_hvn` = 2，中间识别出 LVN
  - 所有成交在一个价格 → POC = VAH = VAL
- **时点**：随机抽取 (日期, 时刻)，删除该时刻之后的全部数据后重算 developing 和前一日 / 复合 Profile，结果必须完全一致
- **细网格合并**：5 个 daily 细网格相加后的复合 Profile，与直接用 5 天 bar 计算的结果一致
- **复权**：KORU 2026-07-15 前后的复合 Profile 连续
- **竞价剔除**：`exclude_close_cross` 开关前后，收盘价附近格子的成交量变化等于 16:00:00 那一秒的成交量
- **清洗**：坏数据时段（如 2026-09-21 11:42–11:44）的成交不进入 Profile
