# 0015 开盘区间与日内高低点分析

日期：2026-10-17　状态：已采纳　依据：用户提问"日内最高最低点如何判断；前 30–90 分钟的走势是否和当天是震荡还是突破有关；
是否要加上盘前、昨天、最近几天；科技股是否要参考 QQQ"

## 背景

日内波动报表（决策 0009–0013）回答"哪只证券适合做"，没有回答"一天之内什么时候、怎么判断高低点"。

## 结论

1. **逐日字段放进日内波动报表的每日计算**（`daily_metrics.opening_range`，参数 `opening_windows_min`，默认 30/60/90）：
   开盘区间最高、最低、第 n 分钟末的价格、之后的最高最低、第一次向上 / 向下突破的时刻。全部以 ADR 为单位、相对开盘价，
   用清洗后的 1 分钟 bar。这些字段只给分析模块用，不进报表的汇总表（`aggregate` 按前缀跳过），报表排名不受影响。
2. **分析模块 `trader.analytics.opening`**：
   - 高低点时刻分布（`extremes_histogram`）和"前 n 分钟内已出现"的比例（`extremes_summary`）；
   - 走势分类（`day_outcomes`）：区间内 / 单边突破（收盘在突破一边之外）/ 突破后收回 / 双向突破；
   - 第 n 分钟时已知的特征（`features`）：区间宽度、价格在区间的位置、跳空、盘前振幅、开盘在昨天区间的位置、昨天振幅和实体比例、
     最近 5 天平均振幅和涨跌、QQQ 的同样特征、是否和 QQQ 同向。特征只用第 n 分钟以前的数据，结果只用之后的数据；
   - 分档对比（`conditional`、`factor_summary`）：不用回归或机器学习，三等分后看各档比例的差，结果使用者自己能读懂；
   - QQQ：同步程度（`ref_sync`），以及个股第一次突破时 QQQ 的状态和突破结果（`ref_alignment`，QQQ 的突破时刻 ≤ 个股才算"已突破"，没有未来数据）。
3. notebook `user/notebooks/开盘区间与高低点.ipynb`，默认 10 只科技股 + QQQ，2024-01-02 ~ 2026-10-15，缓存在 `reports/opening_cache/`。
   杠杆 ETF 不放进去（和标的走势相同，会重复计数）。
4. "突破成功"只看收盘是否在区间之外，不是交易盈亏；要回答"追突破能不能赚钱"需要用回测（带止损、成本）。
